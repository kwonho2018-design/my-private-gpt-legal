WORDAY · 워데이

개인정보 처리방침

시행일: 2026년 9월 8일 · 운영자: YOUNGSOO KIM

워데이는 회원가입, 광고, 분석 SDK, 추적 기능 없이 기기 안에서 학습하는 영어 어휘 앱입니다. 개발자 서버로 학습 기록이나 개인정보를 전송하지 않습니다.

1. 앱이 요청하거나 수집하지 않는 정보

이름, 이메일, 생년월일, 위치, 연락처, 사진, 녹음 및 광고 식별자를 학습 기능에서 요청하거나 수집하지 않습니다. 카메라와 마이크를 사용하지 않으며, 로그인 계정을 만들지 않습니다.

2. 기기에 저장되는 학습 기록

단어별 학습 상태, 북마크, 정답과 오답, 복습 예정일, 학습 날짜, 점수, 학년·Day 진도 및 화면·발음 설정을 앱의 기기 저장 공간에 보관합니다. 이어서 학습하고 복습 일정을 보여주기 위한 정보이며 개발자가 원격으로 열람하지 않습니다. 검색어와 스펠링 입력 내용은 별도로 저장하지 않습니다.

3. 보관 및 삭제

학습 기록은 직접 삭제하거나 앱을 삭제할 때까지 기기에 남습니다. 앱 설정의 ‘이 기기의 학습 기록 삭제’에서 진도, 북마크, 학습 기록과 설정을 삭제할 수 있습니다. iOS의 ‘앱 정리하기’는 데이터 삭제와 다릅니다. 기기의 백업 설정에 따라 앱 데이터가 Apple의 백업에 포함될 수 있으며 해당 백업은 Apple 설정에서 관리합니다.

4. 직접 선택하는 백업·복원

백업 기능은 사용자가 직접 선택한 파일 위치에 학습 기록을 JSON 파일로 내보냅니다. 개발자 서버에 업로드하지 않습니다. 파일 앱이나 클라우드 저장소에는 해당 서비스의 정책이 적용됩니다. 앱의 기록을 삭제해도 따로 내보낸 파일이나 기기 백업까지 삭제되지는 않으므로 각 저장소에서 별도로 삭제해야 합니다.

5. 발음과 외부 링크

발음은 iOS의 음성 합성 기능을 사용하고 음성을 녹음하지 않습니다. 사전 출처 등 외부 링크는 사용자가 누를 때 브라우저로 열립니다. 방문한 웹사이트에는 해당 사이트의 개인정보 처리방침이 적용되며, 워데이는 학습 기록을 링크에 첨부하지 않습니다.

6. 어린이를 포함한 모든 학습자

연령이나 학년에 따라 별도의 개인정보를 수집하지 않습니다. 학년 선택은 학습 과정 선택 기능이며 실제 재학 정보나 생년월일을 확인하지 않습니다.

7. 이 웹사이트와 문의

이 안내 페이지는 GitHub Pages에서 제공됩니다. 페이지 방문과 GitHub Issues를 통한 문의에는 GitHub의 개인정보 처리방침이 적용됩니다. 문의를 보내면 공개한 내용과 GitHub 계정 정보가 개발자 및 다른 방문자에게 보일 수 있습니다. 공개 문의에는 비밀번호, 연락처, 아동의 개인정보 또는 학습 백업 파일을 올리지 마세요.

앱 사용, 개인정보, 기록 삭제 및 오류 관련 문의: 개발자 지원 문의. 제목에 ‘워데이’를 적어주세요. 개발자는 사용자가 문의에 제공한 내용을 문의 확인과 해결을 위해 사용합니다.

8. 방침 변경

개인정보 처리 방식이 변경되면 이 페이지와 앱 내부 방침 및 App Store의 개인정보 안내를 갱신합니다.
